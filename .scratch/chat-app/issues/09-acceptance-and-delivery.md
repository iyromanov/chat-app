# 09: Приёмка и подготовка к сдаче

**What to build:** проверяющий получает воспроизводимо запускаемое приложение и проходит согласованные сценарии чата и stories по README; оставшиеся дефекты и ограничения явно разобраны.

**Blocked by:** 05 — Восстановление после сбоев соединения и отправки; 08 — Персональное состояние просмотра историй.

**Status:** ready-for-agent

**Spec:** [Согласованная спецификация](../spec.md).

**User stories:** 60–65; итоговая проверка 1–59.

- [ ] Из чистого окружения, имеющего указанные в README зависимости, Compose собирает и запускает web, API и MongoDB без облачных сервисов. Пользователь открывает один localhost-адрес; HTTP, Socket.io, Swagger UI и видео доступны по описанной схеме.
- [x] README описывает пример окружения, обязательные параметры, локальный и developer-режимы, генерацию OpenAPI/типов, проверки, тесты с Docker, демонстрацию двумя пользователями, постоянные данные и ограничения.
- [x] Выполнены проверки ESLint/Prettier, TypeScript/Svelte, FSD-импортов, независимости пакета контрактов, актуальности OpenAPI и генерируемых HTTP-типов; полный набор Jest HTTP/Socket.io тестов проходит с MongoDB в Testcontainers.
- [x] Ручная проверка Chrome покрывает регистрацию, вход/выход, поиск, один диалог на пару, real-time переписку, историю, infinite scroll, несколько вкладок, потерю связи и ответа отправки, восстановление и истечение JWT. Ошибки, пустые состояния и узкий экран проверены.
- [ ] Ручная проверка Chrome покрывает запись stories со звуком и без микрофона, отказ камеры, таймер, предпросмотр и пересъёмку, публикацию, приватный просмотр, ленту и навигацию, персональные отметки, повторный вход и истечение открытой истории.
- [ ] Перезапуск контейнеров сохраняет пользователей, сообщения, видео и отметки просмотра. Физическая очистка истёкшего видео, метаданных, отметок и файлов без метаданных проверена отдельно; API-отказ не используется как единственное доказательство удаления.
- [ ] Ревью по спецификации и стандартам не выявляет пропущенных критериев или несогласованного расширения объёма; найденные дефекты исправлены в рамках соответствующего поведения и повторно проверены.
- [x] Во всём существующем и новом коде комментарии, включая JSDoc/TSDoc, написаны на английском; весь текст UI и все сообщения об ошибках (валидация, HTTP API, Socket.io и внутренние ошибки приложения) также на английском. Пользовательский контент сохраняет язык пользователя; документация может оставаться на русском.
- [x] Ограничения stateless JWT, возможной задержки событий до синхронизации, поддержки браузеров и обновления stories явно описаны; серверный отзыв токенов, outbox, MinIO и другие исключённые возможности не заявлены реализованными.
- [ ] Исходный код и документация готовы для GitHub-сдачи, проверено отсутствие секретов среди публикуемых файлов. Если GitHub remote уже настроен, README указывает реальный репозиторий; если его нет, явно зафиксирован оставшийся шаг публикации без выдуманного URL и заявления о завершённой внешней публикации.
- [x] Зафиксированы выполненные проверки и фактическое состояние всех задач. При ограничении времени приоритет сохраняет готовый чат, Compose, тесты и README; незавершённые stories сообщаются явно, а эта задача не отмечается полностью выполненной при неполном согласованном объёме.

## Comments

### 2026-10-16 — частичная приёмка и подготовка документации

- README полностью на английском: запуск Compose, окружение, developer-режим, генерация, проверки, тесты с Docker, демонстрация двумя пользователями, постоянные данные и ограничения. Удалены устаревшие заявления о миграции индекса и отмене создания диалога при закрытии поиска.
- [Журнал приёмки](../../../docs/acceptance.md) фиксирует текущие результаты и состояние задач 01–09. Stories 06–08 отсутствуют в коде и остаются блокером полного выполнения 09; их реализация не подменяется документацией или тестами чата. Триажный статус сохранён: отдельного значения завершения в трекере нет.
- Прошли `pnpm check`, `pnpm test` (49 backend-тестов с реальной MongoDB Testcontainers и 69 клиентских проверок) и `pnpm build`. Из чистого снимка отслеживаемых файлов собран отдельный Compose-проект с новой БД, без host node_modules или облачных сервисов. Из-за занятого 8080 проверялся 18080 с соответствующим ORIGIN.
- В Chromium через Chrome DevTools проверены регистрация, вход/ошибки, поиск, пустые состояния, общий диалог, четыре вкладки, сообщения/переносы, потеря ответа после сохранения и повторная отправка, offline-send, reconnect последних 50 и пагинация, infinite scroll пользователей/диалогов, границы 2000/2001, ширина 375 px, приватность, logout и независимый вход. Перезапуск и пересоздание контейнеров сохранили данные.
- Основные перечисленные сценарии чата приняты: истечение JWT дополнительно проверено в браузере подписанным токеном на 15 секунд (сервер завершил подключение, UI показал вход, HTTP вернул 401 при ещё существующей cookie). Проверены mobile Back и logout отключённой вкладки после reconnect. Расширенный ручной прогон остаётся частичным: закрытие/открытие браузера, все варианты focus/scroll и пограничные UI-гонки в этом прогоне не повторены. Видео, отметки просмотра и физическую очистку нельзя принять до реализации 06–08.
- Проверка отслеживаемого дерева не обнаружила распространённых шаблонов секретов; `.env` не отслеживается. Git remote отсутствует: README явно указывает оставшийся шаг создания реального GitHub-репозитория и публикации, без выдуманного URL. Полная готовность исходного согласованного объёма к сдаче не объявляется.
