# 09: Приёмка и подготовка к сдаче

**What to build:** проверяющий получает воспроизводимо запускаемое приложение и проходит согласованные сценарии чата и stories по README; оставшиеся дефекты и ограничения явно разобраны.

**Blocked by:** 05 — Восстановление после сбоев соединения и отправки; 08 — Персональное состояние просмотра историй.

**Status:** ready-for-agent

**Spec:** [Согласованная спецификация](../spec.md).

**User stories:** 60–65; итоговая проверка 1–59.

- [ ] Из чистого окружения, имеющего указанные в README зависимости, Compose собирает и запускает web, API и MongoDB без облачных сервисов. Пользователь открывает один localhost-адрес; HTTP, Socket.io, Swagger UI и видео доступны по описанной схеме.
- [ ] README описывает пример окружения, обязательные параметры, локальный и developer-режимы, генерацию OpenAPI/типов, проверки, тесты с Docker, демонстрацию двумя пользователями, постоянные данные и ограничения.
- [ ] Выполнены проверки ESLint/Prettier, TypeScript/Svelte, FSD-импортов, независимости пакета контрактов, актуальности OpenAPI и генерируемых HTTP-типов; полный набор Jest HTTP/Socket.io тестов проходит с MongoDB в Testcontainers.
- [ ] Ручная проверка Chrome покрывает регистрацию, вход/выход, поиск, один диалог на пару, real-time переписку, историю, infinite scroll, несколько вкладок, потерю связи и ответа отправки, восстановление и истечение JWT. Ошибки, пустые состояния и узкий экран проверены.
- [ ] Ручная проверка Chrome покрывает запись stories со звуком и без микрофона, отказ камеры, таймер, предпросмотр и пересъёмку, публикацию, приватный просмотр, ленту и навигацию, персональные отметки, повторный вход и истечение открытой истории.
- [ ] Перезапуск контейнеров сохраняет пользователей, сообщения, видео и отметки просмотра. Физическая очистка истёкшего видео, метаданных, отметок и файлов без метаданных проверена отдельно; API-отказ не используется как единственное доказательство удаления.
- [ ] Ревью по спецификации и стандартам не выявляет пропущенных критериев или несогласованного расширения объёма; найденные дефекты исправлены в рамках соответствующего поведения и повторно проверены.
- [ ] Во всём существующем и новом коде комментарии, включая JSDoc/TSDoc, написаны на английском; весь текст UI и все сообщения об ошибках (валидация, HTTP API, Socket.io и внутренние ошибки приложения) также на английском. Пользовательский контент сохраняет язык пользователя; документация может оставаться на русском.
- [ ] Ограничения stateless JWT, возможной задержки событий до синхронизации, поддержки браузеров и обновления stories явно описаны; серверный отзыв токенов, outbox, MinIO и другие исключённые возможности не заявлены реализованными.
- [ ] Исходный код и документация готовы для GitHub-сдачи, проверено отсутствие секретов среди публикуемых файлов. Если GitHub remote уже настроен, README указывает реальный репозиторий; если его нет, явно зафиксирован оставшийся шаг публикации без выдуманного URL и заявления о завершённой внешней публикации.
- [ ] Зафиксированы выполненные проверки и фактическое состояние всех задач. При ограничении времени приоритет сохраняет готовый чат, Compose, тесты и README; незавершённые stories сообщаются явно, а эта задача не отмечается полностью выполненной при неполном согласованном объёме.
