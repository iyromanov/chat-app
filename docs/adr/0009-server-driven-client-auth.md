# Авторизация UI по ответам сервера

Для тестового чата клиент проверяет `/me` при запуске и при ошибке подключения socket, выполняет login/register/logout и завершает вход по актуальному HTTP 401 или `auth:ended`. Отказываемся от собственного таймера истечения JWT и localStorage-рассылки logout, чтобы убрать параллельные механизмы смены авторизации; отключённая вкладка может узнать о завершении входа только при следующем обращении к серверу. Сетевая ошибка не считается потерей авторизации, неуспешный серверный logout не объявляется успешным локально.

Backend по-прежнему проверяет JWT и отключает истёкшие соединения. [ADR 0003](0003-stateless-jwt.md) сохраняет stateless JWT, HttpOnly cookie и отсутствие серверного отзыва; это решение уточняет момент обновления UI вкладок. [ADR 0007](0007-authenticated-client-context.md) сохраняет изоляцию контекстов и защиту от устаревшего 401. Согласовано на стадии проектирования; реализация ещё не выполнена.
