# Stateless JWT без серверного отзыва

Используем JWT со сроком 24 часа в HttpOnly cookie без коллекции Session и списка отозванных токенов. Выбрали stateless-проверку подписи и срока вместо чтения серверной сессии на каждый защищённый HTTP-запрос, чтобы упростить тестовое задание.

Выход удаляет cookie, очищает авторизацию вкладок и отключает сокеты текущего входа; независимый вход другого браузера сохраняется. Выход не делает скопированный JWT недействительным: его можно использовать до истечения срока, включая повторное подключение Socket.io. Это осознанно заменяет первоначальное требование немедленного отзыва; при истечении срока HTTP-доступ запрещается и существующие сокеты отключаются.
