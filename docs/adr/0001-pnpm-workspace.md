# Один pnpm workspace для web и API

SvelteKit и NestJS располагаются в `apps/web` и `apps/api` одного pnpm workspace с единым lockfile и корневыми командами разработки, проверок и тестов. Выбрали эту структуру вместо независимых проектов `frontend/` и `backend/`, чтобы совместно поддерживать запуск и зависимости двух приложений в одном тестовом задании. Общие пакеты добавляются при конкретной необходимости; оба приложения обслуживают одну предметную область и используют общий глоссарий.
