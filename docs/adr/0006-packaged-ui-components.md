# Готовые UI-компоненты из npm

Интерфейс использует Flowbite Svelte и Tailwind CSS. Компоненты импортируются напрямую из `flowbite-svelte`; их исходники и локальные обёртки для повторения API библиотеки в проект не копируются. Для оформления используются параметры компонентов; допускается настройка цветов, размеров, скруглений и визуальных состояний через поддерживаемые библиотекой параметры, классы и тему. Tailwind используется для раскладки и этих настроек оформления. Предметные композиции следуют слоям FSD.

Выбрали npm-библиотеку, чтобы получать готовые оформленные компоненты и обновлять их как зависимость, сохраняя небольшой объём собственного UI-кода. Цена решения — зависимость от API и визуального стиля Flowbite; изменение внутреннего поведения требует поддержки библиотекой или отдельного обоснованного решения.

При согласовании редизайна по референсу WhatsApp Web разрешили визуальную настройку компонентов: стандартное оформление ограничивало необходимую компактность и внешний вид. Библиотека сохраняется основой UI; собственные настройки требуют проверки при её обновлении. Границы редизайна описаны в [спецификации](../../.scratch/chat-ui-redesign/spec.md).
